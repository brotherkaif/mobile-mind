# Mobile Mind

## Directories

* [concepts](concepts/) - Durable domain concepts and definitions.
* [concepts/events](concepts/events/) - Events and meetings extracted from journal entries.
* [concepts/projects](concepts/projects/) - Investigations and potential projects extracted from journal entries.
* [references](references/) - Source-backed notes and methodology references.
* [playbooks](playbooks/) - Repeatable operational procedures.
* [assets](assets/) - Raw input artifacts for ingestion.
* [assets/raw/journal](assets/raw/journal/) - Daily bullet-journal capture files (YYYYMMDD.txt).
* [outputs](outputs/) - Generated audits, reports, and exports.
* [.agents/skills](.agents/skills/) - Portable Agent Skills for query, ingest, journal-ingest, maintenance, and audit tasks.
